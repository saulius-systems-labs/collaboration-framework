# Contributing to the Collaboration Framework

This repository defines how we collaborate in a thoughtful, open, and productive way.

## Contribution standards

- be respectful, clear, and constructive
- explain the purpose and context for changes
- keep the process accessible to contributors
- prefer practical and explainable guidance over abstract rules

## We welcome

- improvements to contribution guidance
- clarifications to operational practices
- review and workflow enhancements
- onboarding suggestions
- collaboration templates and process notes

## How to contribute

1. Open an issue for larger ideas or governance discussions.
2. Submit a pull request with a summary and rationale.
3. Keep discussions focused on practical collaboration outcomes.

## Review expectations

Each contribution should answer:
- what problem it addresses
- why the change improves the collaboration model
- how it impacts maintainers and contributors
